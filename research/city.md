# 第 07 章「打印城市」：数据和做法

## 要做什么
滑到第 07 章时先放一段过场：大字 + 小字引入 → 3D 打印机层层打印深圳城市集群 → 「深圳」浮出 → 城市退为本章背景。

## 找过的开源方案
- **OSM / Overpass**：想直接拉平安金融中心周边楼栋的 footprint 与 `height` / `building:levels` 标签，挤出真实体块。
  - `overpass-api.de`、`overpass.kumi.systems`、`overpass.private.coffee`、`overpass.osm.ch`、`overpass.osm.jp` 在本机网络下全部不可达（406 / 超时）；`api.openstreetmap.org` 的 bbox 抓取也超时，且返回的是 XML 全量地图数据，需要再跑 osmium 解析。
- **[OSM2World](https://github.com/OSM2World/osm2world)**、**[3D CityDB](https://github.com/3dcitydb/3dcitydb)**：确认可用，但都需要可访问的 OSM / CityGML 数据源。
- **Sketchfab / Nexprint / 3D Warehouse**：有平安金融中心的模型，但下载需要账号 / 客户端，且许可证多为非商用或未标明，不适合直接进这个仓库。
- B 站「深圳智慧城市开源项目」类视频多是展示用的商业 Cesium/UE 工程，没有可直接用的轻量几何。

## 最终做法：程序化建模
不依赖外部模型，`assets/js/city.js` 用 three.js 现场生成：

- **体块城市**：约 400 个盒体，网格街区 + 街道留白，高度按离中心距离衰减，用 `InstancedMesh` + 逐实例颜色一次性绘制；打印进度按 x 轴从左到右错开，每个楼栋从地面长起。
- **地标**（按公开资料近似）：平安金融中心（600m / 118 层，四段收分方台 + 尖顶）、京基100（442m，椭圆收分）、中国华润大厦「春笋」（392m，锥形）、深交所（抬起的方盘）、市民中心（大屋顶 + 两翼）、深圳湾体育中心「春茧」（穹顶）。
- **深圳湾**：按地理方位近似出的海岸线曲线（城市在北、海在南），水面 + 波纹线，打印到 86% 后淡入。
- **打印机隐喻**：打印前沿是竖直线 + 地面黄线，随 x 扫过；层数读数 000→118（平安金融中心的真实层数），不是编造的进度条。
- **相机**：开场低机位看空打印台，打印时缓慢环绕抬升，完成后拉远；退场后切到宽景作为章节背景（低透明度 + 左侧纸色渐隐保证可读）。
- **主题**：深色 / 浅色两套配色（浅色是深墨线、纸白体块），切换主题时重设材质与体块颜色。
- **降级**：手机、`prefers-reduced-motion`、无 WebGL 时直接跳过过场，保留原来的「建模 / 切片 / 打印」版面和线稿。

## 尺寸与来源（公开资料）
- 平安金融中心：约 600m，118 层，位于福田 CBD。
- 京基100：约 442m。
- 中国华润大厦（春笋）：约 392m。
- 深圳湾位于城市南侧，过场里只取「城市在北、海在南」的方位关系，不代表真实岸线精度。

## 许可
几何与代码为本仓库原创；没有引入任何第三方模型、贴图或城市数据文件。
